#  3D Macera Oyunu - Kaynak Kodları

Bu depo, Unity oyun motoru kullanılarak geliştirilen 3D macera oyununun **sadece kaynak kodlarını (C# Scriptleri)** içermektedir. 

## Neden Sadece Kodlar?
Oyun içerisinde kullanılan yüksek çözünürlüklü 3D çevre modelleri, kaplamalar (texture) ve ses dosyalarının toplam boyutu GitHub'ın dosya yükleme sınırlarını aştığı için, projeyi incelemek isteyenler adına yalnızca oyunun temel mekaniklerini ve işleyişini gösteren yazılım kısmı herkese açık olarak paylaşılmıştır.

##  Kodların İçerdiği Temel Mekanikler
* **Oyuncu Kontrolcüsü (Player Controller):** Karakterin/Aracın hareket ve fizik dinamikleri.
* **Tetikleyici (Trigger) Sistemleri:** Belirli alanlara girildiğinde çalışan olaylar (jumpscare, kapı açılma vb.).
* **Arayüz Yönetimi (UI Manager):** Oyun içi ekranlar ve etkileşim kodları.
